# 🐧 Linux Practice Notes — Day 04

## 📅 Topic

Processes, Services, and Logs

---

# 🔍 Process Checks

## 1. Check Running Processes

### Command

```bash
ps aux
```

### Observation

* Displays all running processes
* Shows CPU and memory usage
* Helps identify active applications and services

---

## 2. Monitor Live Processes

### Command

```bash
top
```

### Observation

* Shows real-time system resource usage
* Displays CPU load and memory consumption
* Useful during troubleshooting

---

## 3. Find a Specific Process

### Command

```bash
pgrep nginx
```

### Observation

* Returns the process ID (PID) of nginx
* Useful for checking whether a process is running

---

# ⚙️ Service Checks

## 4. Check Service Status

### Command

```bash
systemctl status nginx
```

### Observation

* Confirms whether nginx is active or failed
* Shows uptime and recent logs
* Displays service startup information

---

## 5. Check if Service Starts on Boot

### Command

```bash
systemctl is-enabled nginx
```

### Observation

* Confirms whether nginx starts automatically during boot

---

## 6. List Running Services

### Command

```bash
systemctl list-units --type=service
```

### Observation

* Lists active systemd services
* Helps identify running background services

---

# 📜 Log Checks

## 7. View Service Logs

### Command

```bash
journalctl -u nginx
```

### Observation

* Displays logs generated by nginx
* Useful for debugging startup or configuration issues

---

## 8. View Recent Log Entries

### Command

```bash
tail -n 50 /var/log/messages
```

### Observation

* Shows the latest 50 log entries
* Helps identify recent system activity and errors

---

# 🛠️ Mini Troubleshooting

## Problem

Nginx service failed to start after configuration changes.

---

## Troubleshooting Steps

### Validate Nginx Configuration

```bash
nginx -t
```

### Restart Service

```bash
systemctl restart nginx
```

### Check Logs

```bash
journalctl -u nginx -n 20
```

---

## What I Learned

* Logs help quickly identify service issues
* `systemctl status` provides immediate health information
* Process inspection is essential during troubleshooting
