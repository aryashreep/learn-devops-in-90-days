Before You Begin — Setup & Prerequisites

Prerequisites Checklist

  • GitHub account (free) — for forking the repo and submitting daily solutions
  • WSL2 (Windows) or a Linux VM or macOS Terminal — required for all labs
  • VS Code with the Remote-WSL extension (or any terminal editor)
  • Free cloud tier: AWS Free Tier or GCP Free Tier (needed from Day 08)
  • Docker Desktop (free for personal use) — required from Day 31

Day 00 — Pre-Work (complete before Day 01)

Get Your Environment Ready
  1. Fork this repo to your GitHub account
  2. Install VS Code + the Remote-WSL extension
  3. Enable WSL2 on Windows (or set up an Ubuntu VM) — follow the Microsoft guide
  4. Create a free AWS Free Tier account
  5. Post "Day 00 — Starting my DevOps journey!" on LinkedIn with #LearnDevOpsIn90Days
