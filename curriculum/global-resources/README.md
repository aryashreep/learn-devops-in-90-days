## ☁️ Free Cloud Tiers
Don't spend a paisa while learning! Start with these:
- **[AWS Free Tier](https://aws.amazon.com/free/):** 12 months of EC2, S3, and more.
- **[Azure for Students](https://azure.microsoft.com/en-us/free/students/):** $100 credit + free services (No credit card required).
- **[Google Cloud Free Trial](https://cloud.google.com/free):** $300 credit for 90 days.
- **[Oracle Cloud Free Tier](https://www.oracle.com/cloud/free/):** Always Free services (Great for ARM instances).

- **[Visual Studio Code](https://code.visualstudio.com/):** The only IDE you'll ever need.
