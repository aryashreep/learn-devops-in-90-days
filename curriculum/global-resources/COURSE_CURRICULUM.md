# 🗺️ 15-Module DevOps Academy Curriculum

This is the definitive roadmap for your 90-day DevOps journey. Follow this sequence to transform from a beginner to a production-ready DevOps engineer.

---

## 📦 Phase 1: The Foundations (Days 1-15)
### Module 1: Introduction To DevOps, Cloud & SRE
- DevOps Culture & Mindset
- The "Wall of Confusion"
- C.A.L.M.S. Framework
- The 8-Stage Lifecycle

### Module 2: Linux Foundations
- Kernel, Shell & System Layers
- Command Line Mastery (Navigation, Search, I/O)
- Users, Groups & Permissions
- Service Management (systemd)

### Module 3: Networking & System Design
- DNS, IP, and Subnets
- OSI Model for DevOps
- Ports, Protocols & Firewalls
- SSH & Secure Communication

---

## 🐙 Phase 2: Code, Git & Project Management (Days 16-30)
### Module 4: Shell Scripting For DevOps
- Automating repetitive tasks
- Logic, Loops, and Functions in Bash

### Module 5: Introduction to Git [GitHub & GitLab]
- Version Control Fundamentals
- Branching Strategies (GitFlow)
- Collaborative Pull Requests

### Module 6: Jira For DevOps
- Agile & Scrum Methodology
- Ticket Lifecycles in CI/CD

---

## 🐳 Phase 3: Containers & Pipelines (Days 31-50)
### Module 7: Docker
- Images, Containers, and Registries
- Dockerfile Best Practices
- Multi-container apps with Docker Compose

### Module 8: CI-CD Pipelines (GitHub Actions)
- Cloud-native automation
- Building & Testing in the Cloud

### Module 9: CI-CD Pipelines (Jenkins)
- Master/Agent Architecture
- Declarative Pipelines as Code

---

## ☸️ Phase 4: Orchestration & Provisioning (Days 51-75)
### Module 10: Kubernetes (CKA)
- Pods, Deployments, and Services
- Cluster Administration & Troubleshooting

### Module 11: Terraform
- Infrastructure as Code (IaC)
- Provisioning AWS/Azure with Code

### Module 12: Ansible
- Configuration Management
- Standardizing server environments

---

## 📊 Phase 5: Advanced Ops & Portfolio (Days 76-90)
### Module 13: SRE & Observability
- Monitoring with Prometheus & Grafana
- Centralized Logging

### Module 14: GitOps on Kubernetes
- ArgoCD & Helm
- Declarative environment syncing

### Module 15: Capstone Projects
- **Project 1:** Netflix Clone Deployment
- **Project 2:** End-to-End AWS Pipeline
- **Project 3:** SRE Dashboard Implementation
