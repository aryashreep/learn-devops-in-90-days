## 🛠️ Step-by-Step Command History

### 1. Branching Out
```bash
# Golu creating his dev world
$ git checkout -b dev
Switched to a new branch 'dev'

# Hack! (Adding file)
$ touch new_feature.txt
$ git add .
$ git commit -m "feat: added experimental button"
```

### 2. Remote Connection
```bash
# Linking local repo to GitHub
$ git remote add origin https://github.com/golu-devops/90-days-devops-practice.git

# Verify remote
$ git remote -v
origin  https://github.com/golu-devops/90-days-devops-practice.git (fetch)
origin  https://github.com/golu-devops/90-days-devops-practice.git (push)
```

### 3. Pushing to Cloud
```bash
# Pushing both worlds
$ git push -u origin main
$ git push origin dev
```
