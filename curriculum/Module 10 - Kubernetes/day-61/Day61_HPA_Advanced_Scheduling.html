HPA & Advanced Scheduling

Day 61: Auto-scaling & Scheduling Taints ☸️

Naked
"Jagu, it is difficult to manually scale pods during high load. And how can we prevent normal web apps from running on expensive GPU nodes?"
"Golu! K8s uses Horizontal Pod Autoscaler (HPA) for automatic scaling which scales-up/down by tracking metrics. And to keep node routing strict we use Node Affinity and Taints & Tolerations!"
Section

1. Learning Objectives

Horizontal scaling automation set karna, specialized nodes configure karna, aur scheduling algorithms control karna.

  • Metrics Server: Real-time consumption telemetry for Pods/Nodes.
  • HPA: Auto-scaling pod count based on CPU threshold.
  • Scheduling: Node Affinity, Taints and Tolerations.
2. Analogy & Mental Model

Think of HPA and scheduling like **building permissions and security**:

  • HPA (The Shift Manager): Monitors queues. If customers line up, he calls more cashiers. When queues clear, he sends cashiers home.
  • Taints (Node - Keep Out Sign): Applied to a room (e.g. "Cleanroom - No Entry"). Repels all visitors.
  • Tolerations (Pod - Hazmat Suit): The visitor's gear. Only visitors wearing the Hazmat Suit (Toleration) can enter the Cleanroom (Tainted Node).
  • Node Affinity (Node Preferences): The pod's preference: "I like rooms with SSD windows."
3. Did You Know?
HPA
Requires Metrics Server to be active to trace CPU metrics
NoSchedule
Taint effect preventing new pods without tolerations from scheduling
Required
Hard affinity rules that must be met, otherwise Pod stays Pending
4. Key HPA & Scheduling Manifests

HorizontalPodAutoscaler: hpa.yaml

apiVersion: autoscaling/v2
kind: HorizontalPodAutoscaler
metadata:
  name: web-hpa
spec:
  scaleTargetRef:
    apiVersion: apps/v1
    kind: Deployment
    name: web-deployment
  minReplicas: 2
  maxReplicas: 10
  metrics:
  - type: Resource
    resource:
      name: cpu
      target:
        type: Utilization
        averageUtilization: 50

Node Toleration inside Pod Spec:

spec:
  containers:
  - name: gpu-worker
    image: my-ai-model:latest
  tolerations:
  - key: "hardware"
    operator: "Equal"
    value: "gpu"
    effect: "NoSchedule"
5. Key Concepts & Scheduling Algorithms

Taints & Tolerations

Applied to Node to repel pods. To bypass the taint, the pod spec must have matching tolerations. Important for isolating nodes for specific licenses, groups, or hardware.

Node Affinity

Attracts pods to nodes based on labels (similar to nodeSelector, but more powerful with logical operators). Can be requiredDuringSchedulingIgnoredDuringExecution (hard rules) or preferredDuringSchedulingIgnoredDuringExecution (soft rules).

6. Compare: Node Affinity vs Taints & Tolerations
Node Affinity
  • Applied to Pods
  • Attracts Pods to specific Node labels
  • Does not prevent other Pods from scheduling on those Nodes
VS
Taints & Tolerations
  • Taint applied to Nodes; Toleration to Pods
  • Repels Pods from Node
  • Guarantees ONLY pods with toleration can go to that Node
7. Real-World Troubleshooting Example

Incident: A Pod stays in Pending state, scheduler says 0/3 nodes are available: 1 node(s) had untolerated taint, 2 Insufficient cpu.

Resolution: The engineer inspects Node labels and taints. They realize all healthy workers are tainted for specialized operations. The developer must add matching tolerations to the Pod manifest or increase node CPU resources.

8. Common Misconceptions
  • ❌ Myth: HPA works without resources limit configs.
  • ✔️ Reality: HPA calculates target CPU percentages based on the Pod's resource **request**. If you don't define resource requests, HPA cannot work.
  • ❌ Myth: Taints attract Pods with tolerations.
  • ✔️ Reality: Taints only **repel**. A pod with toleration can go to tainted nodes, but can also schedule on normal untainted nodes. Use Affinity + Taints together to isolate nodes.
9. Try It Yourself

Taint a node and test scheduling via CLI:

# Apply taint to node1
kubectl taint nodes node1 type=gpu:NoSchedule

# List node taints
kubectl describe node node1 | grep Taints

# Remove taint
kubectl taint nodes node1 type=gpu:NoSchedule-
10. Quick Summary
  • HPA scales pod replicas based on metrics like CPU usage.
  • Taints repel workloads; tolerations allow bypass.
  • Node Affinity attracts pods to nodes with specific labels.
