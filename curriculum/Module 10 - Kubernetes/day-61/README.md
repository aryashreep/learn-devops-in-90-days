# 🗓️ Day 61 — HPA & Advanced Scheduling

Welcome to **Day 61** of the **#LearnDevOpsIn90Days** challenge! 🚀

## 🎯 Today's Goal
Configure autoscaling using the Horizontal Pod Autoscaler (HPA), and master advanced scheduling features including Node Affinity, Taints, and Tolerations.

## 🧠 Key Learnings
- Installing metrics server and running HPA configurations.
- Auto-scaling deployments based on CPU load.
- Attracting pods to specific hardware using Node Affinity.
- Isolating node workloads using Taints and Tolerations.
