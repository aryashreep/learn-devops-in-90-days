# 🗓️ Day 59 — StatefulSets & DaemonSets

Welcome to **Day 59** of the **#LearnDevOpsIn90Days** challenge! 🚀

## 🎯 Today's Goal
Understand specialized Kubernetes controllers: deploy databases using StatefulSets with Headless Services, run per-node agents using DaemonSets, and execute batch runs using Jobs and CronJobs.

## 🧠 Key Learnings
- Stateful workloads vs. Stateless workloads.
- Ordered startup and sticky identities of StatefulSets.
- Deploying logging/monitoring agents on every node using DaemonSets.
- Automating batch operations via Jobs and CronJobs.
