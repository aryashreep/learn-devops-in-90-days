# 🗓️ Day 58 — Volumes, PV, PVC & Storage Classes

Welcome to **Day 58** of the **#LearnDevOpsIn90Days** challenge! 🚀

## 🎯 Today's Goal
Learn how Kubernetes handles data persistence, write PersistentVolume (PV) and PersistentVolumeClaim (PVC) manifests, and understand static vs. dynamic provisioning using StorageClasses.

## 🧠 Key Learnings
- Container data persistence using volumes.
- Decoupling storage from application code using PV and PVC.
- Storage classes and dynamic provisioning.
- Mounting PVCs inside Pod configurations.
