# 🗓️ Day 62 — Helm Package Manager

Welcome to **Day 62** of the **#LearnDevOpsIn90Days** challenge! 🚀

## 🎯 Today's Goal
Learn how to use **Helm** to package and manage your Kubernetes applications, configure `values.yaml` files, and manage application release cycles (install, upgrade, list, rollback).

## 🧠 Key Learnings
- Helm architecture and directory layout.
- Helm repositories and fetching pre-made charts.
- Installing, listing, upgrading, and rolling back releases using Helm CLI.
