# 🗓️ Day 53 — Kubernetes Architecture & Cluster Setup (using Kind)

Welcome to **Day 53** of the **#LearnDevOpsIn90Days** challenge! 🚀

## 🎯 Today's Goal
Understand the master-worker architecture of Kubernetes, learn the roles of core Control Plane and Node components, and set up a local multi-node cluster using **Kind**.

## 🧠 Key Learnings
- The control plane vs. worker node architecture model.
- Essential components: API Server, etcd, Scheduler, Controller Manager, Kubelet, and Kube-proxy.
- Setting up a multi-node cluster using `Kind` (Kubernetes in Docker).
- Interacting with the cluster using `kubectl`.
