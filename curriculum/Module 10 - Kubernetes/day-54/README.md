# 🗓️ Day 54 — Kubernetes Manifests & Your First Pods

Welcome to **Day 54** of the **#LearnDevOpsIn90Days** challenge! 🚀

## 🎯 Today's Goal
Learn the difference between imperative and declarative deployments, write your first Pod YAML manifest, launch it, and practice basic debugging commands (`describe`, `logs`, `port-forward`).

## 🧠 Key Learnings
- What is a Pod and its lifecycle.
- Imperative vs Declarative management models.
- Structure of K8s manifests (apiVersion, kind, metadata, spec).
- Debugging basic workloads.
