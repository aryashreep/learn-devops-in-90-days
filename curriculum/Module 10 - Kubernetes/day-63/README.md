# 🗓️ Day 63 — Capstone: WordPress + MySQL on Kubernetes

Welcome to **Day 63** of the **#LearnDevOpsIn90Days** challenge! 🚀

## 🎯 Today's Goal
Deploy a full-stack production-ready stateful application on Kubernetes. You will configure, deploy, link, and test WordPress and MySQL databases.

## 🧠 Key Learnings
- Architectural combination of stateful and stateless application layers.
- Inter-pod connectivity using Services.
- Mounting persistent storage to containers.
- Exposing application configurations via Secrets.
