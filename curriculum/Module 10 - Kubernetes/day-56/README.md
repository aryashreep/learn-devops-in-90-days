# 🗓️ Day 56 — Kubernetes Services & Gateway API

Welcome to **Day 56** of the **#LearnDevOpsIn90Days** challenge! 🚀

## 🎯 Today's Goal
Learn how Kubernetes manages internal networking, create ClusterIP and NodePort Services, and explore routing external traffic using the modern **Gateway API**.

## 🧠 Key Learnings
- Networking isolation and load balancing using Services.
- Internal service discovery using CoreDNS.
- Setting up HTTPRoute and understanding the Gateway API architecture.
