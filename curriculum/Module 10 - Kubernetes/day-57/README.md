# 🗓️ Day 57 — ConfigMaps & Secrets

Welcome to **Day 57** of the **#LearnDevOpsIn90Days** challenge! 🚀

## 🎯 Today's Goal
Learn how to separate configuration details and sensitive credentials from application code using ConfigMaps and Secrets, and inject them into running workloads.

## 🧠 Key Learnings
- Storing configurations in ConfigMaps.
- Storing sensitive credentials in Secrets.
- Encoding credentials in base64.
- Mounting configurations as environment variables in Pods.
