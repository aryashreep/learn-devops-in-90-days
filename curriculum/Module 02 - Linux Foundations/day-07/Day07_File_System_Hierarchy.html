🎯 LEARNING OBJECTIVES
  • Navigate: Understand the root (/) and its subdirectories.

💡 Kyu Seekhein? Kyunki server setup karte waqt agar galat folder mein file daali, toh system crash ho sakta hai!

💡 ANALOGY: The Organized Apartment

1. / (Root): Pura Apartment Complex.
2. /etc (Kitchen): Jahan saari recipes (Configs) rakhi hain.
3. /bin (Toolbox): Jahan repair ke tools (Commands) hain.
4. /var (Dustbin/Meter): Jahan kachra (Logs) aur readings (Variable data) hain.
5. /home (Bedrooms): Aapka personal space.

📂 The SRE's Map — Directory Breakdown
  • ⚙️ /etc → Editable Text Configurations (Super important!).
  • 📜 /bin → Binaries needed for single-user mode.
  • 🔍 /var/log → Log files (History book of the OS).
  • 📦 /opt → Optional software (Third party tools).
  • 💻 /dev/null → The "Black Hole" (Send unwanted output here).
📌 Key Concepts: The Root Tree
/ (ROOT)
│
├── bin (Commands)
├── etc (Configs)
├── home (Users)
├── var (Logs)
└── dev (Devices)

Everything starts from /. There is no `C:` or `D:` drive in Linux!

⚠ COMMON MISCONCEPTIONS
  • Myth: Hidden files (starting with `.`) are encrypted/secure.
  • Reality: Nahi! Wo sirf `ls` command se hide hoti hain. `ls -a` se koi bhi dekh sakta hai.
  • Myth: `/dev/null` file space khaati hai.
  • Reality: It's a special file. Jo bhi isme dalo, wo gayab ho jata hai. No space used!
▶ TRY IT YOURSELF: Nav-Drill

1. cd / && ls -F (Please check root par)

2. ls -lh /var/log (look at the size of the logs)

3. tree -L 1 / (Level 1 tree structure dekho)
