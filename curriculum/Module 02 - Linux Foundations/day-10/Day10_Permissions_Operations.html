Bhai, Aaj Kya Seekhenge?

Aaj hum Linux permissions (rwx) ko decode karenge. UGO model, Octal (4-2-1) calculation, aur system files pe access control kaise set karte hain.

🎯 LEARNING OBJECTIVES
  • Interpret: Decode the 10-character permission string (`-rwxr-xr--`).
  • Calculate: Convert symbolic permissions to Octal (e.g., 755, 644).
  • Modify: Use `chmod` to add or remove access securely.
  • Standardize: Identify industry standards for file and directory permissions.
💡 ANALOGY: The House Keys

1. User (u): Ghar ka Malik (Has keys to all rooms).
2. Group (g): Family members (Can enter, but maybe not open the safe).
3. Others (o): Delivery boys/Guests (Can reach the gate, but not enter).
4. rwx: Read (Dekhna), Write (Badalna), Execute (Andar jana/Run karna).

📌 Key Concepts: Octal Notation

Read (r)

4

Write (w)

2

Exec (x)

1

Sum karo: r(4) + w(2) + x(1) = 7 (Full Access)

🔄 Compare: 755 vs 644

755 (Executables)

"Owner can do anything. Team & World can only Read & Execute."

Standard for Scripts and Directories.

VS

644 (Configs)

"Owner can Edit. Team & World can only Read."

Standard for Settings and Config files.

⚠ COMMON MISCONCEPTIONS
  • Myth: Directory permissions bina 'x' ke cd kar sakte hain.
  • Reality: Nahi! Directory mein 'cd' karne ke liye Execute (x) power zaroori hai.
  • Myth: chmod 777 errors fix karne ka best tarika hai.
  • Reality: Ye security suicide hai! Always give **Least Privilege**.
