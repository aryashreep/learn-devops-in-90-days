# 🗓️ Day 06 — Linux Fundamentals: Read and Write Text Files

Welcome to **Day 06** of the **#LearnDevOpsIn90Days** challenge 🚀

## 🎯 Today's Goal
Master the art of creating and manipulating text files. Logs, configs, and scripts are all text files—if you can handle them quickly, you can debug and automate like a pro!

## 🧠 Key Learnings
- Creating empty files with `touch`.
- Writing and Appending data using **Redirection** (`>` and `>>`).
- Reading files efficiently with `cat`, `head`, and `tail`.
- Using `tee` to write to a file and see it on the screen at the same time.
