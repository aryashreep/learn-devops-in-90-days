# ☁️ Module 11: Terraform [IaC]

Welcome to **Module 11**! In this module, we dive into **Infrastructure as Code (IaC)** using **Terraform** by HashiCorp. Terraform is the industry-standard tool for provisioning and managing cloud infrastructure across AWS, Azure, GCP, Kubernetes, and hundreds of other providers using declarative HCL (HashiCorp Configuration Language).

---

## 🎯 Module Overview
This 7-day module will take you from Terraform beginner to confident practitioner, covering everything from basic resource provisioning to multi-environment infrastructure with workspaces.

| Day | Topic | Key Focus |
|---|---|---|
| **Day 64** | [Introduction to Terraform & First AWS Infra](./day-64/README.md) | IaC concepts, Terraform installation, AWS credentials setup |
| **Day 65** | [Providers, Resources & Dependencies](./day-65/README.md) | HCL syntax, provider configuration, resource blocks, depends_on |
| **Day 66** | [Variables, Outputs, Data Sources & Expressions](./day-66/README.md) | Input variables, outputs, data blocks, built-in functions |
| **Day 67** | [State Management & Remote Backends](./day-67/README.md) | State file management, S3 backend, DynamoDB state locking |
| **Day 68** | [Terraform Modules](./day-68/README.md) | Custom modules, module registry, reusable infrastructure |
| **Day 69** | [Provision EKS Cluster with Modules](./day-69/README.md) | AWS EKS provisioning, VPC design, kubectl integration |
| **Day 70** | [Capstone: Multi-Environment Workspaces](./day-70/README.md) | Workspaces, environment isolation, dynamic configurations |
