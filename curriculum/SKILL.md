## 3. PEDAGOGICAL STRUCTURE (THE 11 ELEMENTS)

Follow this exact sequence for every training module:
1.  **LEARNING OBJECTIVES:** Goal-setting + "Kyu Seekhein?" (Consequences/Stake-setting).
2.  **ANALOGY:** High-level mental model (Golu & Jagu conversation).
3.  **DID YOU KNOW?:** 3-column stats/fun facts.
4.  **Key Directories — What Lives Where:** File system context with micro-doodle icons (Gears, Houses, etc.).
5.  **Key Concepts:** Technical deep-dive with CSS-based diagrams/onion models.
6.  **Compare (What can go wrong):** Split-screen "VS" layout (Dangerous vs. Secure).
7.  **REAL-WORLD EXAMPLE:** Story-based troubleshooting (e.g., Netflix, Amazon scenarios).
8.  **COMMON MISCONCEPTIONS:** Myth vs. Reality list.
9.  **TRY IT YOURSELF:** Hands-on CLI practice commands.
10. **QUICK SUMMARY:** Bullet-first recap.
11. **MINI QUIZ:** 7-question knowledge check + PDF-friendly Footer Answer Key.
