# 🗓️ Day 29 — Introduction to Jira: Managing the Chaos

Welcome to **Day 29**! Today we move from the terminal to the project board. If Git is the "Time Machine" for code, Jira is the "Command Center" for the team.

## 🎯 Today's Goal
Understand what Jira is, why DevOps teams use it, and how to navigate the Jira interface.

## 🧠 Key Learnings
- **The Concept:** Why spreadsheets are not enough for DevOps.
- **Project Types:** Software Projects (Scrum/Kanban) vs Business Projects.
- **Cloud vs Data Center:** Understanding the different Jira deployments.
- **The Dashboard:** Your personal view of the project's health.
