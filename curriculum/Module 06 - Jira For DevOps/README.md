# 🎫 Module 06: Jira For DevOps

Welcome to **Module 06**! In this module, we move from managing code (Git) to managing work and projects. Jira is the industry standard for tracking tasks, bugs, and agile progress in DevOps teams.

## 🎯 Module Overview
This 7-day module will take you from creating your first ticket to automating complex DevOps workflows and integrating Jira with GitHub.

| Day | Topic | Key Focus |
|---|---|---|
| **Day 29** | Intro to Jira | Projects, Cloud vs Data Center, Basic UI. |
| **Day 30** | Issues & Hierarchy | Epics, Stories, Tasks, and Bugs. |
| **Day 31** | Agile Methodologies | Scrum vs Kanban, Backlog, Sprints. |
| **Day 32** | Estimation & Velocity | Story Points, Burndown charts, Planning. |
| **Day 33** | Workflows & Automation | Transitions, Triggers, and Auto-assignment. |
| **Day 34** | DevOps Integration | Linking GitHub, Smart Commits, Release Tracking. |
| **Day 35** | Reporting & JQL | Search with JQL, Custom Dashboards. |
