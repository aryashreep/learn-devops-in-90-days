# 🛡️ Module 08: DevSecOps

Welcome to **Module 08**! In this module, we embed security into every stage of the CI/CD pipeline — from code commit to production deployment. DevSecOps shifts security left, catching vulnerabilities early and automatically blocking builds when critical threats are detected.

## 🎯 Module Overview
This 1-day intensive module covers the complete DevSecOps pipeline architecture: SAST (Static Analysis), DAST (Dynamic Analysis), SCA (Software Composition Analysis), container security with hadolint &amp; Trivy, secret scanning with GitLeaks, OWASP ZAP runtime testing, severity gating, and orchestrating 10+ reusable workflows from a single master pipeline.
