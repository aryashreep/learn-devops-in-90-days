# 🗓️ Day 23 — Git Branching and Working with GitHub

Welcome to **Day 23**! Today we expand our Time Machine into the **Multiverse**. You will learn how to work on new features in parallel without ever breaking your main production code.

## 🎯 Today's Goal
Master Git Branching and connect your local work to the cloud (GitHub). Learn how to create "Parallel Realities" for your code and merge them back together.

## 🧠 Key Learnings
- **The Branch Concept:** Why we use `main` for production and `dev` for features.
- **Local Branching:** Commands like `git branch` and `git checkout`.
- **Remote Connections:** Linking to GitHub with `git remote add`.
- **The Cloud Push:** Moving local history to the remote server with `git push`.
