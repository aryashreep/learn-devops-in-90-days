# 🏆 Module 01 Mastery Exam: Introduction to DevOps, Cloud & SRE

Welcome to the **Mastery Exam** for Module 01! Test your understanding of DevOps culture, principles, the Wall of Confusion, C.A.L.M.S. framework, the DevOps lifecycle, Cloud fundamentals, and Site Reliability Engineering.

---

### 📝 30 Multiple Choice Questions

#### 🧠 Section 1: DevOps Fundamentals (1–10)

1. **What is DevOps?**
   - A) A specific software tool for deployment
   - B) A culture and methodology that combines Development and Operations
   - C) A programming language for automation
   - D) A database management system
   - **Answer:** B

2. **Which of the following best describes the primary goal of DevOps?**
   - A) Eliminate all manual testing
   - B) Increase the number of developers in a team
   - C) Deliver high-quality software faster by breaking silos between Dev and Ops teams
   - D) Replace Operations teams with automated scripts
   - **Answer:** C

3. **The "Wall of Confusion" in traditional IT refers to:**
   - A) A firewall between the database and the application
   - B) A communication barrier between Development and Operations teams
   - C) A network security protocol
   - D) The learning curve for new DevOps engineers
   - **Answer:** B

4. **In a traditional IT setup, what is the primary concern of the Operations team?**
   - A) Shipping new features as fast as possible
   - B) Code quality and syntax
   - C) Stability, uptime, and reliability of the production environment
   - D) Writing unit tests
   - **Answer:** C

5. **In a traditional IT setup, what is the primary concern of the Development team?**
   - A) Server uptime and monitoring
   - B) Rapid feature delivery and code changes
   - C) Database administration
   - D) User support tickets
   - **Answer:** B

6. **DevOps is often visualized as an infinite loop. How many stages does the standard DevOps lifecycle include?**
   - A) 4 — Plan, Build, Test, Deploy
   - B) 6 — Code, Build, Test, Release, Deploy, Monitor
   - C) 8 — Plan, Code, Build, Test, Release, Deploy, Operate, Monitor
   - D) 10 — Ideate, Plan, Code, Build, Test, Stage, Release, Deploy, Operate, Observe
   - **Answer:** C

7. **The phrase "You build it, you run it" is most closely associated with:**
   - A) Waterfall methodology
   - B) Traditional IT operations
   - C) DevOps culture
   - D) Agile software development only
   - **Answer:** C

8. **Which of the following is NOT a benefit typically attributed to adopting DevOps practices?**
   - A) Faster time to market
   - B) Improved collaboration between teams
   - C) Guaranteed zero production incidents
   - D) Increased deployment frequency
   - **Answer:** C

9. **DevOps is best described as:**
   - A) A single tool like Jenkins or Docker
   - B) A role limited to senior engineers only
   - C) A cultural movement emphasizing automation, measurement, and sharing
   - D) A cloud service provider
   - **Answer:** C

10. **Amazon is known to deploy code to production approximately every:**
    - A) 11.7 hours
    - B) 11.7 minutes
    - C) 11.7 seconds
    - D) 11.7 days
    - **Answer:** C

#### 🔄 Section 2: C.A.L.M.S. Framework (11–16)

11. **The acronym C.A.L.M.S. stands for:**
    - A) Culture, Automation, Lean, Measurement, Sharing
    - B) Code, Automation, Linux, Monitoring, Security
    - C) Cloud, API, Logging, Metrics, Scaling
    - D) Continuous, Agile, Lean, Managed, Secure
    - **Answer:** A

12. **In the C.A.L.M.S. framework, what does the 'C' stand for?**
    - A) Code
    - B) Cloud
    - C) Culture
    - D) Container
    - **Answer:** C

13. **The 'A' in C.A.L.M.S. emphasizes:**
    - A) Architecture design
    - B) Automation of repetitive tasks
    - C) Application performance
    - D) Access control
    - **Answer:** B

14. **'Lean' in the C.A.L.M.S. framework focuses on:**
    - A) Reducing server costs
    - B) Small batches, fast feedback, and eliminating waste
    - C) Writing less code
    - D) Using fewer tools
    - **Answer:** B

15. **The 'M' in C.A.L.M.S. stands for Measurement. Which metrics are most relevant in a DevOps context?**
    - A) Lines of code written per day
    - B) Number of meetings attended
    - C) MTTR (Mean Time to Recovery) and deployment frequency
    - D) Total hours spent in training
    - **Answer:** C

16. **'Sharing' in C.A.L.M.S. encourages teams to:**
    - A) Keep their knowledge private to maintain job security
    - B) Share only through formal documentation
    - C) Share knowledge, tools, and successes across teams
    - D) Share passwords and credentials openly
    - **Answer:** C

#### ☁️ Section 3: Cloud & Infrastructure (17–22)

17. **Which of the following is a key characteristic of Cloud Computing?**
    - A) Physical servers must be purchased upfront
    - B) On-demand self-service and pay-as-you-go pricing
    - C) Capacity is fixed and cannot be changed
    - D) Infrastructure must be managed manually at all times
    - **Answer:** B

18. **Netflix runs its infrastructure entirely on which cloud platform?**
    - A) Google Cloud Platform (GCP)
    - B) Microsoft Azure
    - C) Amazon Web Services (AWS)
    - D) IBM Cloud
    - **Answer:** C

19. **What does IaaS stand for in cloud computing?**
    - A) Infrastructure as a Service
    - B) Integration as a Service
    - C) Internet as a Service
    - D) Identity as a Service
    - **Answer:** A

20. **Which cloud service model provides a platform to develop and deploy applications without managing underlying infrastructure?**
    - A) IaaS (Infrastructure as a Service)
    - B) PaaS (Platform as a Service)
    - C) SaaS (Software as a Service)
    - D) FaaS (Function as a Service)
    - **Answer:** B

21. **Scalability in cloud computing refers to:**
    - A) The ability to manually upgrade physical hardware
    - B) The ability to automatically adjust resources based on demand
    - C) The ability to deploy code without testing
    - D) The ability to reduce the number of developers needed
    - **Answer:** B

22. **Which of the following is an example of SaaS?**
    - A) Amazon EC2
    - B) Google Compute Engine
    - C) Gmail
    - D) Kubernetes
    - **Answer:** C

#### 🛠️ Section 4: SRE & DevOps Practices (23–30)

23. **SRE stands for:**
    - A) System Reliability Engineering
    - B) Site Reliability Engineering
    - C) Service Recovery Engineering
    - D) Software Release Engineering
    - **Answer:** B

24. **An SRE team's primary focus is to:**
    - A) Write all the application code for a product
    - B) Ensure systems are reliable, scalable, and have appropriate SLIs/SLOs
    - C) Manage the company's finances
    - D) Design the user interface of applications
    - **Answer:** B

25. **What is an SLO in the context of SRE?**
    - A) Service Level Objective — a target reliability level for a service
    - B) System Log Output — a debugging mechanism
    - C) Simple Load Optimizer — a performance tool
    - D) Service Licensing Order — a procurement process
    - **Answer:** A

26. **The "First Step" recommended in the curriculum to begin a DevOps career is:**
    - A) Learning Kubernetes
    - B) Mastering Terraform
    - C) Linux and Scripting fundamentals
    - D) Jenkins and CI/CD pipelines
    - **Answer:** C

27. **Automation in DevOps primarily aims to:**
    - A) Replace all developers with scripts
    - B) Reduce manual, repetitive work and minimize human error
    - C) Increase the number of steps in a deployment process
    - D) Eliminate the need for monitoring
    - **Answer:** B

28. **Which of the following best describes the relationship between Agile and DevOps?**
    - A) Agile replaces DevOps entirely
    - B) DevOps extends Agile principles to operations, creating a seamless delivery pipeline
    - C) Agile is only for testing, DevOps is only for deployment
    - D) They are unrelated methodologies
    - **Answer:** B

29. **What is the primary purpose of monitoring in a DevOps lifecycle?**
    - A) To track how many lines of code each developer writes
    - B) To collect feedback from production systems that feeds back into planning and improvement
    - C) To schedule team stand-up meetings
    - D) To restrict access to production systems
    - **Answer:** B

30. **Which company is credited with pioneering both SRE and large-scale DevOps practices?**
    - A) Microsoft
    - B) Google
    - C) Facebook
    - D) IBM
    - **Answer:** B
