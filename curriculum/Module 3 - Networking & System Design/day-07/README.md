# 🗓️ Day 07 — Networking Basics for DevOps

Welcome to **Day 07** of the **#LearnDevOpsIn90Days** challenge 🚀

## 🎯 Today's Goal
Understand how computers talk to each other. This is the foundation for Cloud and Kubernetes networking.

## 🧠 Key Learnings
- IP Addresses (Public vs Private) and Subnets.
- The OSI Model: A simplified view for DevOps.
- Understanding ICMP and using `ping` and `traceroute`.
- Basics of the TCP/UDP protocols.
