# 🗓️ Day 09 — DNS & Load Balancing Concepts

Welcome to **Day 09** of the **#LearnDevOpsIn90Days** challenge 🚀

## 🎯 Today's Goal
Demystify how "google.com" turns into an IP address and how high-traffic sites stay online.

- Troubleshooting DNS with `dig` and `nslookup`.
- Introduction to Load Balancing (High Availability).
- Concepts of Round Robin and health checks.
