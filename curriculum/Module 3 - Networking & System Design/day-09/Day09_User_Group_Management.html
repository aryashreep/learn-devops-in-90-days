🎯 LEARNING OBJECTIVES
  • Organize: Create multiple users with home directories.

📌 Key Concepts: The Identity Toolkit
  • useradd -m: Creates a new user with a home folder.
  • groupadd: Creates a new team bucket.
  • usermod -aG: Adds a user to a group without removing old ones.
  • chgrp: Changes the group ownership of a file/folder.
🔄 Compare: Primary vs Secondary Group

Primary Group

"Aapka asli khandaan—jab aap file banate ho, ye group owner banta hai."

VS

Secondary Group

"Aapke extra teams (e.g. Sudo, Docker)—temporary extra powers ke liye."

⚠ COMMON MISCONCEPTIONS
  • Myth: User delete karne se uski files auto-delete ho jati hain.
  • Reality: Nahi! Files 'Orphan' ban jati hain. `-r` flag use karna padta hai remove karne ke liye.
  • Myth: Ek user sirf ek hi group mein reh sakta hai.
  • Reality: User ek Primary aur unlimited Secondary groups ka member ho sakta hai.
