# 🗓️ Day 08 — Ports, Protocols & Firewalls

Welcome to **Day 08** of the **#LearnDevOpsIn90Days** challenge 🚀

## 🎯 Today's Goal
Learn how to secure your infrastructure by managing ports and firewalls.

## 🧠 Key Learnings
- Common ports: 22 (SSH), 80 (HTTP), 443 (HTTPS), 3306 (MySQL).
- Checking open ports with `netstat` and `ss`.
- Introduction to firewalls (`ufw` or `iptables`).
- Scanning for vulnerabilities with `nmap`.
