# Lab Session: Firewall Security
## Task
- Use `netstat -tuln` to see all open ports on your machine.
- Enable `ufw` (if on Ubuntu) and allow only SSH and HTTP ports.
- Deny a specific port and verify it is blocked.
- Use `nmap` to scan your localhost for open ports.
