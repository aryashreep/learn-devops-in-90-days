# Lab Session: SSH Key Mastery
## Task
- Generate a new SSH key pair using `ssh-keygen`.
- Set up a config file in `~/.ssh/config` with a host alias.
- Practice "password-less" login to a remote server or a VM.
- Create an SSH tunnel to forward a local port to a remote one.
