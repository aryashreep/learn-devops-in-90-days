# 🗓️ Day 10 — SSH & Secure Shell Mastery

Welcome to **Day 10** of the **#LearnDevOpsIn90Days** challenge 🚀

## 🎯 Today's Goal
Master the tool that 99% of DevOps remote work is done through: SSH.

## 🧠 Key Learnings
- Password-based vs Key-based authentication (RSA/ED25519).
- Managing `authorized_keys` and `known_hosts`.
- Using SSH Config files for easy server access.
- Basic SSH Tunneling and Port Forwarding.
