## 🎯 Task Objectives
- Implement multi-stage builds in a Dockerfile.
- Shrink image size using Alpine runtimes.
- Tag and push built images to Docker Hub.

## 🛠️ Hands-on Challenges

1. **Challenge 1:** Write a multi-stage Dockerfile for a React application (Stage 1: Node builder to compile, Stage 2: Nginx host runner).
2. **Challenge 2:** Compare the final image size against a single-stage Node image. Document details.
3. **Challenge 3:** Create a Docker Hub account, tag the image using your repository name, and push it.
