# 🗓️ Day 31 — Introduction to Docker

Welcome to **Day 31** of the **#LearnDevOpsIn90Days** challenge 🚀

## 🎯 Today's Goal
Understand what Docker is, how it differs from virtual machines, and run your very first container.

## 🧠 Key Learnings
- The difference between containers and virtual machines.
- Docker architecture: Daemon, CLI, Registry, Images, Containers.
- Running your first container with \`docker run hello-world\`.
- Listing, pulling, and inspecting Docker images.

## Why This Matters for DevOps
Docker is the foundation of modern DevOps. Every CI/CD pipeline, every microservice, and every cloud deployment relies on containerization. Understanding Docker is the first step to mastering Kubernetes, serverless, and cloud-native development.
