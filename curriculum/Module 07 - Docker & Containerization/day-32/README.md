# 🗓️ Day 32 — Docker Images & Container Lifecycle

Welcome to **Day 32** of the **#LearnDevOpsIn90Days** challenge 🚀

## 🎯 Today's Goal
Master the commands to pull, run, inspect, stop, and clean up Docker containers.

## 🧠 Key Learnings
- The difference between read-only Docker Images and writeable Container layers.
- Standard container states: Created, Running, Stopped, Paused, Deleted.
- Using container CLI switches like interactive (`-it`), detached (`-d`), port-mapping (`-p`), and volume-mapping (`-v`).
