1. LEARNING OBJECTIVES & WHY SEEKHEIN

Dockerfile 'Infrastructure as Code' hai. Setup instructions ko code mein likhne se manually configure karne ki mistakes khatam hoti hain aur environment consistent rehta hai.

  • Write standard Dockerfiles with correct layering.
  • Understand layering mechanisms and caching behavior.
  • Use CMD vs ENTRYPOINT for container boot executables.
🥞 The Dockerfile Layer Cake

Every instruction in a Dockerfile adds a read-only layer to the image. Caching checks if the files/commands changed before executing. Put static steps first!

FROM node:24        # Base Layer (OS + Node)
WORKDIR /app        # Metadata change
COPY package.json . # Layer Cached (unless dependencies change)
RUN npm install     # Heavy install cached!
COPY . .            # Code copy (changes often, placed last)
CMD ["npm", "start"] # Startup config
⚖️ Comparison: ADD vs. COPY & CMD vs. ENTRYPOINT
ADD vs COPY

COPY handles simple local files.
ADD allows fetching from remote URLs and auto-extracting archives (which is often hidden/insecure).

VS
CMD vs ENTRYPOINT

ENTRYPOINT makes the container run as an executable.
CMD acts as default arguments that can be overridden at runtime.

🎬 Real World Troubleshooting: Slow Builds

React codebase mein developers direct COPY . . ke baad RUN npm install kar rahe the. Isse har code change pe modules re-download hotey the. DevOps team ne layers divide ki, cache apply kiya, aur build time 10 mins se 12 seconds par le aayi!

⌨️ Try It Yourself

Build and run your image:

# Build and tag
docker build -t my-app:1.0 .

# Run with port mapping
docker run -p 8080:3000 my-app:1.0
📝 Day 31 Mini Quiz
1. What is the difference between ADD and COPY in a Dockerfile?
A) COPY is used for volumes, ADD is for files B) ADD can download files from a URL and extract archives; COPY only copies from local filesystem C) COPY is deprecated and ADD should always be used D) There is no difference; they are aliases
2. If you define both ENTRYPOINT and CMD in a Dockerfile, which one takes priority?
A) ENTRYPOINT runs first, and CMD is appended as default arguments to it B) CMD takes absolute priority and ignores ENTRYPOINT C) They run in parallel D) The build throws a parser error

Answer Key:

1: B (ADD supports URL/tar), 2: A (ENTRYPOINT with CMD arguments)
