# 🧪 Lab Session: Day 31 — Dockerfile: Build Your Own Images

**Jagu:** "Beep Boop! Golu, ab hum rasoi se nikal kar khud ki recipe book (Dockerfile) likhenge. Ek ek line se image ki layer banegi!"

## 🎯 Task Objectives
- Write a Dockerfile for a Node.js web application.
- Utilize Docker build caching by ordering directives.
- Contrast CMD and ENTRYPOINT instructions.

## 🛠️ Hands-on Challenges

1. **Challenge 1:** Create a small Express/React app directory and write a Dockerfile starting `FROM node:24`.
2. **Challenge 2:** Build the image tagged `my-node-app:1.0`.
3. **Challenge 3:** Change code in the app and re-run the build. Document which steps were fetched from 'CACHED' and explain why.
