## 🎯 Task Objectives
- Define a multi-service config inside docker-compose.yml.
- Start, stop, and clean up stacks with single commands.
- Verify volume mapping persistence under Compose.

## 🛠️ Hands-on Challenges

1. **Challenge 1:** Write a `docker-compose.yml` declaring an Nginx web server and a Redis cache service.
2. **Challenge 2:** Configure a named volume for Redis data persistence inside the YAML.
3. **Challenge 3:** Spin up the stack in detached mode using Compose, view status with `docker compose ps`, and tear it down.
