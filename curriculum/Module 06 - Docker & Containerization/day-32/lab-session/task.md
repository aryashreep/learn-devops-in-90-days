# 🧪 Lab Session: Day 32 — Docker Volumes and Networking

**Jagu:** "Beep Boop! Golu, container temporary hote hain par data permanent hona chahiye. Aaj hum safe storage (Volumes) aur clear talks (Networks) seekhenge!"

## 🎯 Task Objectives
- Create persistent Docker volumes for databases.
- Setup custom bridge networks for container-to-container talks.
- Map internal ports to the host system.

## 🛠️ Hands-on Challenges

1. **Challenge 1:** Create a persistent volume named `db-volume` and run a MySQL or Postgres container utilizing it.
2. **Challenge 2:** Create a custom bridge network called `app-network`.
3. **Challenge 3:** Launch a web application container and database container on `app-network`, and demonstrate they communicate using container names.
