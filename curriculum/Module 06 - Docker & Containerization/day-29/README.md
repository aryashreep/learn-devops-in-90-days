# 🗓️ Day 29 — Introduction to Docker

Welcome to **Day 29** of the **#LearnDevOpsIn90Days** challenge 🚀

## 🎯 Today's Goal
Understand containerization, the difference between VMs and containers, and Docker architecture.

## 🧠 Key Learnings
- Why virtualization leads to resource wastage and dedicated operating system overhead.
- How containerization shares host resources to achieve high utilization and microsecond boot times.
- The components of the Docker Engine: Docker Client, Docker Daemon, and Docker Registry.
