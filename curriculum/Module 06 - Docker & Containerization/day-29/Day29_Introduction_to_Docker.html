🏠 Mental Model: Physical House vs. Furnished Appt

Agar poora ghar doosre desh bhejna ho to base, deewar, plumbing sab le jaana padega—ye Virtual Machine hai. Agar sirf kapde le kar ek fully furnished flat mein shift hona ho—ye Docker Container hai. Base infrastructure (Host OS Kernel) pehle se wahan hai, aap bas apna application package chalate hain.

📁 File System & System Directories

Where does Docker live in Linux? Important paths:

  • /var/lib/docker: Base directory where containers, images, volumes, and networks data are stored.
  • /etc/docker/daemon.json: Configuration file for customizing the Docker daemon settings.
  • /var/run/docker.sock: The Unix socket that the Docker Client uses to communicate with the Daemon.
⚙️ VM vs. Container Architecture

In VM architecture, a Hypervisor runs guest OS instances. In Container architecture, the Docker Engine interfaces directly with the Host OS Kernel, launching light isolated runtimes.

Docker Engine Client-Server Architecture

[Client (CLI Tool)] ---> [Docker Daemon (dockerd)] ---> [Registry (Docker Hub)]

⚖️ Comparison: Hypervisor vs. OS Virtualization
Virtual Machine (Hypervisor)
  • Heavyweight guest OS on each VM.
  • Slow startup (minutes).
  • Pre-allocated RAM/Disk (wasted resources).
VS
Docker Container (OS-level)
  • Lightweight, shares host OS kernel.
  • Instant startup (milliseconds).
  • Dynamic memory consumption (no pre-allocation).
🎬 Real World Troubleshooting: Netflix Microservices

Netflix pe agar hume "Recommendation Engine" update karna ho, to hum poora server reboot nahi karte. Hum us service ka container destroy karke naya image deploy karte hain. Isse baaki services (video streaming, billing) ko rti bhar bhi farq nahi padta!

💡 Common Misconceptions
  • Myth: Containers are secure sandbox virtual machines.
    Reality: Containers are processes. If a container runs as root, it can compromise the host kernel if not configured safely.
  • Myth: Docker can run any OS on any host natively.
    Reality: Docker containers share the host kernel. Linux containers need a Linux kernel (or a VM helper like WS2 in Windows).
