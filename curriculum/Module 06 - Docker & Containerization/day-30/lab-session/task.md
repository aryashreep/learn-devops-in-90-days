# 🧪 Lab Session: Day 30 — Docker Images & Container Lifecycle

**Jagu:** "Beep Boop! Golu, images humare recipes hain aur container pakki hui biryani. Aaj hum is cycle ko control karna seekhenge!"

## 🎯 Task Objectives
- Pull and run containers in detached and interactive modes.
- Check logs and enter running containers.
- Understand container filesystem isolation.

## 🛠️ Hands-on Challenges

1. **Challenge 1:** Pull Nginx image, run it in background mapping port 8080 to 80, and verify it in browser.
2. **Challenge 2:** Use `docker exec -it` to open bash inside the Nginx container, create a file `/usr/share/nginx/html/index.html` with custom message, and verify changes.
3. **Challenge 3:** Stop, start, and remove the container, verifying when the custom file disappears.
