# 🐳 Module 06: Docker & Containerization

Welcome to **Module 06**! In this module, we transition from source control and networking foundations to containerization. Docker is the industry standard for wrapping applications and their environments into lightweight, reliable packages that run identically anywhere.

## 🎯 Module Overview
This 9-day module covers everything from basic container runtimes to multi-container microservices and production image optimization.

| Day | Topic | Key Focus |

| **Day 31** | [Dockerfile Basics](./day-31/README.md) | Custom image building, Caching & Layers. |
| **Day 32** | [Volumes & Networking](./day-32/README.md) | Port Mapping, Bridge Networks, Persistent Storage. |

| **Day 35** | [Multi-Stage Builds & Hub](./day-35/README.md) | Optimizing build contexts, Tagging & Pushes. |
| **Day 36** | [Dockerizing a Full App](./day-36/README.md) | E2E Capstone: Containerize a multi-tier application. |
