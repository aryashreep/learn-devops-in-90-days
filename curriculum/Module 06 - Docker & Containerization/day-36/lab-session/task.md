# 🧪 Lab Session: Day 36 — Docker Project: Dockerize a Full Application

**Jagu:** "Beep Boop! Golu, aaj tumhara final test hai containerization ka. Ek complete web application (Frontend + Backend + DB) ko deploy karo!"

## 🎯 Task Objectives
- Write optimized multi-stage Dockerfiles.
- Compose the services on a secure backend network.
- Demonstrate persistent database storage.

## 🛠️ Hands-on Challenges

1. **Challenge 1:** Use the provided sample app (or bootstrap a simple React-Node-Postgres stack).
2. **Challenge 2:** Create Dockerfiles: Node backend (multi-stage) and React frontend (multi-stage hosting on Nginx). Add `.dockerignore`.
3. **Challenge 3:** Write `docker-compose.yml` linking web, backend, and postgres services with volume persistence. Verify the app runs synchronously on host port 80.
