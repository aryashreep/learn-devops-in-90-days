🏗️ Infrastructure: The Backbone

Routers vs Switches vs Hubs

"Golu, there is a difference between 'Dimaag' and 'Postman' in the network!"

  • Hub (The Dumbest): Data is sent to everyone (Broadcast). Pure chaos!
  • Switch (The Smart One): Sends only what it is intended for (Unicast via MAC).
  • Router (The Legend): Connects different networks (Gateway).
☁️ Data Centers & The Edge

CDN & Edge Locations

"If there is a server in the US, how does the video move fast in India?"

CDN (Content Delivery Network): Aapke ghar ke paas wali Kirana Shop. Sara saaman (Data) wahan pehle se cached hota hai!
  • Region: Physical location in the world.
  • Availability Zone (AZ): One or more data centers.
  • Edge Location: Cache storage sites for CDN.

🔍 DNS: The 4-Step Journey
  1. Recursive Resolver: Your ISP (The middleman).
  2. Root Nameserver: The "." (The Grandfather).
  3. TLD Nameserver: The ".com", ".in" (The Manager).
  4. Authoritative Nameserver: The "GitHub.com" (The actual owner).
