**Jagu:** "Beep Boop! Welcome to Networking, Golu. Har DevOps engineer ko networking ka basic gyaan hona zaroori hai. Aao aaj hum seekhein ki kaise hum apne server ki identity check karte hain aur connectivity verify karte hain!"

## 🎯 Task Objectives
- Find your public IP address using command line.
- Verify internet connectivity using diagnostic tools.

## 🛠️ Hands-on Challenges

1.  **Identity Check:** Use `curl` to find your public IP address using `ifconfig.me` or another public ip echo service.
2.  **Connectivity Test:** Use `ping` to verify your server or machine's connection to `google.com` by sending 5 packets.
