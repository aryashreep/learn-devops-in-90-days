# 🧪 Lab Session: Day 22 — My First Jira Project

**Jagu:** "Beep Boop! Golu, aaj hum tera pehla 'Project' setup karenge. Yaad rakh, bina project ke Jira sirf ek khali killa hai!"

## 🎯 Task Objectives
- Create a free Atlassian account.
- Initialize your first 'Kanban' project.
- Familiarize yourself with the Jira sidebar and Navigation.

## 🛠️ Hands-on Challenges

1.  **The Hub:** Go to [atlassian.com](https://www.atlassian.com/software/jira) and sign up for a free Cloud account.
2.  **The Creation:** 
    - Click **Create Project**.
    - Choose **Kanban** template.
    - Set the name to `DevOps-Mission`.
3.  **The Landscape:** 
    - Explore the **Backlog** view.
    - Check the **Board** (To Do, In Progress, Done).
    - Navigate to **Project Settings** to see available options.
4.  **The Profile:** Set your avatar and time zone in profile settings.
