# 🗓️ Day 23 — Issues & Hierarchy: The Building Blocks

Welcome to **Day 23**! Today we learn about the DNA of Jira: **Issues**. Everything you do in Jira, from fixing a bug to launching a new feature, is an Issue.

## 🎯 Today's Goal
Understand the different types of Jira issues and how they fit into a hierarchy.

## 🧠 Key Learnings
- **Epics:** The big goals (e.g., "Build a Login System").
- **Stories:** User requirements (e.g., "As a user, I want to login via Google").
- **Tasks & Sub-tasks:** The actual work (e.g., "Setup OAuth API").
- **Bugs:** When things go wrong.
