# 🧪 Lab Session: Day 23 — Issues & Hierarchy

**Jagu:** "Beep Boop! Golu, aaj hum tere project ka 'Epic' structure banayenge. Socho ki tum ek e-commerce site bana rahe ho!"

## 🎯 Task Objectives
- Create an Epic.
- Link multiple User Stories and Tasks to that Epic.
- Create a Bug and link it to a Task.

## 🛠️ Hands-on Challenges

1.  **The Big Goal:** 
    - Go to your Jira project.
    - Click **Create** and select Issue Type: **Epic**.
    - Summary: `User Management System`.
2.  **The User Stories:** 
    - Create a **Story**: `As a user, I want to sign up with my email.`
    - Link it to the `User Management System` epic.
3.  **The Technical Task:**
    - Create a **Task**: `Database setup for Users table.`
    - Link it to the same epic.
4.  **The Tiny Details:**
    - Open the `Database setup` task.
    - Click **Add sub-task**.
    - Sub-task: `Install PostgreSQL`.
5.  **The Problem:**
    - Create a **Bug**: `Signup button not clicking on Mobile.`
    - Link it as "is blocked by" or "relates to" the Signup Story.
