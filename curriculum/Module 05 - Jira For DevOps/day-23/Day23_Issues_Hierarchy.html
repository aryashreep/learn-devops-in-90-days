📐 THE HIERARCHY
EPIC (The Goal)
⬇
STORY / TASK (The Requirement)
⬇
SUB-TASK (The Action)

*Bugs can appear at any level, but usually occur in the Story/Task niche!*

📋 COMMON ISSUE TYPES
  • Epic: A big feature that may take a week to complete. (e.g., User Authentication).
  • User Story: User ki requirement. "As a [user], I want [action] so that [value]".
  • Task: Technical work that is necessary for the story.
  • Bug: What should be going on is not going on!
