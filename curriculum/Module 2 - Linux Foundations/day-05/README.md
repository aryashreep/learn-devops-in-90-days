# 🗓️ Day 05 — Linux Troubleshooting Runbook

Welcome to **Day 05** of the **#LearnDevOpsIn90Days** challenge 🚀

## 🎯 Today's Goal
Learn how to diagnose and fix common Linux performance and system issues like a Senior SRE.

## 🧠 Key Learnings
- Monitoring CPU and RAM with `top` and `htop`.
- Checking disk space with `df` and `du`.
- Analyzing system logs in `/var/log`.
- Identifying and killing zombie processes.
