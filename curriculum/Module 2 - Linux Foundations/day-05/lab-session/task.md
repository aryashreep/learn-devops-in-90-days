# Lab Session: System Diagnosis
## Task
- Run `top` or `htop` and identify the process consuming the most CPU.
- Check disk usage using `df -h` and identify the largest partition.
- List the last 50 lines of the system syslog file.
- Practice killing a dummy process (e.g., a `sleep 1000` process).
