# 🧪 Lab Session: Day 06 — File I/O Practice

**Jagu:** "Beep Boop! Golu, aaj hum 'Writer' banenge. Linux mein har cheez ek file hai, isliye file ko handle karna seekhna bahut zaroori hai!"

## 🎯 Task Objectives
- Practice basic file creation and reading.
- Master the difference between Overwriting and Appending.
- Learn to "Tee" your output.

## 🛠️ Hands-on Challenges

1.  **The New Born:** Create a file named `notes.txt` using the `touch` command.
2.  **The First Word:** Write "Line 1: This is my DevOps journey" into the file using the `>` operator.
3.  **The Growth:** Add "Line 2: I am learning Linux foundations" to the same file without deleting the first line (Hint: use `>>`).
4.  **The Double Power:** Use the `tee` command to add "Line 3: Today is Day 06" to the file and see it appearing on your terminal at the same time.
5.  **The Peek:** 
    - Use `cat` to see the full content.
    - Use `head -n 2` to see only the first 2 lines.
    - Use `tail -n 1` to see only the last line.
