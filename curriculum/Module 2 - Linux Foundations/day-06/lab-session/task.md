# Lab Session: Service Management
## Task
- Install a simple package (e.g., `tree` or `htop`) using your package manager.
- Create a simple script that writes the date to a file every 5 seconds.
- Wrap that script into a custom `systemd` service unit.
- Start and enable your custom service and verify its status.
