# 🗓️ Day 06 — Package Managers & systemd

Welcome to **Day 06** of the **#LearnDevOpsIn90Days** challenge 🚀

## 🎯 Today's Goal
Understand how software is installed on Linux and how to manage background services using `systemd`.

## 🧠 Key Learnings
- Mastering `apt` (Debian/Ubuntu) vs `yum/dnf` (RHEL/CentOS).
- Managing services with `systemctl` (start, stop, enable, status).
- Creating your own custom `systemd` service unit.
- Troubleshooting service failures with `journalctl`.
