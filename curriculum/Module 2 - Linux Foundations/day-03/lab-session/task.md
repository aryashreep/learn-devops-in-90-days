# 🧪 Lab Session: Day 03 — Command Toolkit Challenge

**Jagu:** "Golu, DevOps engineer ka sabse bada hathyaar 'Terminal' hota hai. Aaj hum tumhara toolkit (Cheat Sheet) taiyaar karenge!"

## 🎯 Task Objectives
- Categorize 20+ essential commands.
- Master network troubleshooting basics.
- Build a quick-reference guide.

## 🛠️ Hands-on Challenges

1.  **Categorization:** Group your commands into: Navigation, File Ops, Process Management, and Networking.
2.  **Navigation Master:** Include `pwd`, `ls`, `cd`, `pushd/popd`.
3.  **File Wizard:** Include `touch`, `cp`, `mv`, `rm`, `cat`, `head`, `tail`.
4.  **Network Detective:** Practice and record:
    - `ip addr` (To see your IP).
    - `ping google.com` (To check internet).
    - `curl -I google.com` (To see headers).
5.  **The Log Hunt:** Use `tail -f` on a dummy file while writing to it from another terminal.
