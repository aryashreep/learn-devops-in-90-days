# 🗓️ Day 11 — File Ownership Challenge (chown & chgrp)

Welcome to **Day 11**! Today we complete the security puzzle by learning how to change the "Malik" (Owner) and the "Team" (Group) of any file or folder.

## 🎯 Today's Goal
Master the `chown` and `chgrp` commands to manage system ownership precisely.

## 🧠 Key Learnings
- Understanding user and group ownership.
- Using `chown` to change the owner of a file.
- Using `chgrp` to change the group ownership.
- Recursive ownership changes with the `-R` flag.
