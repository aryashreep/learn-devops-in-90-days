Bhai, Aaj Kya Seekhenge?

Aaj hum Linux ke powerful searching tools master karenge: `find` for files, `grep` for text, aur piping techniques. Ab system mein kuch bhi gum nahi hoga!

🎯 LEARNING OBJECTIVES
  • Discover: Use `find` to locate files by name, size, and date.
  • Filter: Master `grep` to search text inside any file.
  • Identify: Learn `locate`, `which`, and `whereis`.
  • Automate: Use Pipes (|) to chain search results.

💡 Kyu Seekhein? Kyunki server par hazaron log files hoti hain—correct information jaldi dhundna hi real skill hai!

📂 Search Anchors — Where to Look
  • 🔍 /var/log → Search here for Errors and System messages.
  • ⚙️ /etc → Search here for Configuration files.
  • 📦 /usr/bin → Search here for Command binaries.
📌 Key Concepts: The Power Duo

find (The Scout)

"File ka address dhundta hai."

find /var/log -name "*.log"
AND

grep (The X-Ray)

"File ke andar jhaankta hai."

grep "error" syslog

Piping them together: find . -name "*.conf" | xargs grep "port"

🔄 Compare: find vs locate

find

"Live scan karta hai. Thoda slow par accurate (Fresh data)."

VS

locate

"Database check karta hai. Super fast par purana data ho sakta hai."

🏢 REAL-WORLD EXAMPLE: The Heavy Log File
Jagu
"Bhai, disk space full ho gayi!
Jaldi se dhundo kaunsi log file 100MB se upar hai."

The Fix: find /var/log -type f -size +100M

"Scout Jagu ne turant culprit file pakad li!"

⚠ COMMON MISCONCEPTIONS
  • Myth: `grep` sirf text files ke liye hai.
  • Reality: `grep` kisi bhi command output ko filter karne ke liye best hai (e.g. `ps aux | grep nginx`).
  • Myth: `find` sirf name se dhundta hai.
  • Reality: It can find by user, permissions, size, and last modified date!
▶ TRY IT YOURSELF

1. find ~ -name "notes.txt" (Golu apni note dhundo)

2. grep -i "error" /var/log/syslog (System ke dukh-dard dekho)

3. which docker (Check karo docker kahan chupa hai)

✓ QUICK SUMMARY
  • find: Discover file locations.
  • grep: Search text patterns.
  • locate: Ultra-fast indexed search.
  • which: Find executable paths.
