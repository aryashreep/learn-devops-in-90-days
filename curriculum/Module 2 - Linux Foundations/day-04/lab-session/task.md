# 🧪 Lab Session: Day 04 — Searching Mastery

**Jagu:** "Beep Boop! Golu, aaj hum Linux ke 'Detective' banenge. System mein kuch bhi dhundna ho, ye commands tumhare sabse bade dost hain!"

## 🎯 Task Objectives
- Master the `find` command for file discovery.
- Use `grep` to peek inside files like a pro.
- Understand the difference between `locate`, `which`, and `whereis`.

## 🛠️ Hands-on Challenges

1.  **The Log Hunter:** Find all files ending in `.log` inside the `/var/log` directory.
2.  **Error Search:** Use `grep` to find the word "error" (case-insensitive) in all those log files.
3.  **Big File Alert:** Search the `/etc` directory for any file larger than 1MB.
4.  **Binary Trace:** Use `which` to find the exact path of the `python3` or `git` binary.
5.  **Piping Fun:** List all files in `/bin` and use `grep` to show only those that contain the word "zip".
