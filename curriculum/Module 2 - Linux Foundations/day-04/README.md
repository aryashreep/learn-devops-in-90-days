# 🗓️ Day 04 — Advanced Navigation & Searching

Welcome to **Day 04** of the **#LearnDevOpsIn90Days** challenge 🚀

## 🎯 Today's Goal
Master the art of finding anything in a Linux system. No more "Where is that file?" moments.

## 🧠 Key Learnings
- Using `find` to locate files by name, size, and date.
- Mastering `grep` for searching text within files.
- Understanding `locate` and `which` commands.
- Piping search results into other commands.
