# 🗓️ Day 13 — Linux Volume Management (LVM)

Welcome to **Day 13**! Today we learn the "Elastic" way of managing disks. In DevOps, servers grow, and you need to know how to add space without losing data.

## 🎯 Today's Goal
Understand Physical Volumes (PV), Volume Groups (VG), and Logical Volumes (LV).

## 🧠 Key Learnings
- The limitations of traditional partitions.
- Creating and extending Logical Volumes.
- Resizing filesystems on the fly.
- Real-world use cases for LVM in servers.
