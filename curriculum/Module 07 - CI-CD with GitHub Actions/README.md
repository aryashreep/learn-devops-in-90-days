# 🤖 Module 07: CI/CD with GitHub Actions

Welcome to **Module 07**! In this module, we dive into Continuous Integration and Continuous Delivery (CI/CD) using GitHub Actions. Automation is at the heart of DevOps, and GitHub Actions provides an incredibly powerful, native platform to test, build, containerize, and deploy applications automatically.

## 🎯 Module Overview
This 12-day module covers everything from YAML basics and basic workflow setup to Docker registries, matrix parallel builds, cloud OIDC integrations, security hardening, and debugging.

| Day | Topic | Key Focus |
|---|---|---|

| **Day 39** | [What is CI/CD?](./day-39/README.md) | The assembly-line model, CI vs CD delivery and deployment. |
| **Day 40** | [Your First GitHub Actions Workflow](./day-40/README.md) | Events, jobs, steps, runners, and first pipeline logs. |
| **Day 41** | [Triggers and Matrix Builds](./day-41/README.md) | Manual/scheduled triggers and multi-environment matrix runs. |
| **Day 42** | [Runners: Hosted vs Self-Hosted](./day-42/README.md) | VM configurations, private networks, and runner scaling. |
| **Day 43** | [Jobs, Steps, Env Vars and Conditionals](./day-43/README.md) | needs dependency keywords, env scoping, and if expressions. |
| **Day 44** | [Secrets, Artifacts and Running Real Tests in CI](./day-44/README.md) | Encrypted settings, build output upload/download, and dependency caching. |
| **Day 45** | [Docker Build and Push in GitHub Actions](./day-45/README.md) | Login actions, Docker Hub push, and layer build caching. |
