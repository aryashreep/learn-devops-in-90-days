Day 43 \u2022 Events, Schedules & Multi-Version Testing \U0001f3af

\U0001f916 "Golu, har workflow ek event se trigger hota hai — push, PR, schedule, ya manual. Matrix build se ek hi workflow multiple OS/versions pe test kar sakta hai!"
\U0001f4a1 Workflow Triggers
EventTriggerUse Case

workflow_dispatchManual button clickManual deploy, ad-hoc tasks
releaseRelease publishedDeploy new versions
\U0001f504 Matrix Strategy
jobs:
  test:
    runs-on: ${{ matrix.os }}
    strategy:
      matrix:
        os: [ubuntu-latest, windows-latest]
        node: ['16', '18', '20']
        include:
          - os: ubuntu-latest
            node: '20'
            experimental: true
      fail-fast: false
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with:
          node-version: ${{ matrix.node }}
      - run: npm test

This generates 6 parallel jobs (2 OS x 3 Node versions)!

\U0001f4cd Matrix Options
OptionPurposeDefault
matrixDefine combination axesRequired
includeAdd extra combinationsNone
excludeRemove specific combosNone

\u23f0 Cron Schedule Examples
on:
  schedule:
    - cron: '0 0 * * *'     # Daily at midnight UTC
    - cron: '30 8 * * 1-5'  # Weekdays 8:30 AM UTC
    - cron: '0 */6 * * *'   # Every 6 hours
    - cron: '0 2 * * 0'     # Weekly on Sunday 2 AM

Cron format: minute hour day month weekday

2. Matrix build mein 'fail-fast: false' kya karta hai?

A) Sab jobs fail ho jayenge   B) Ek fail pe baaki continue   C) Matrix disable ho jayega   D) Jobs skip ho jayenge

Answers: 1-C, 2-B
