# 🗓️ Day 51 — DevSecOps: Add Security & Debugging

Welcome to **Day 51** of the **#LearnDevOpsIn90Days** challenge 🚀

## 🎯 Today's Goal
Lock down workflow permissions, inspect security controls, use debug tools, and output custom job summaries.

## 🧠 Key Learnings
- Apply the Principle of Least Privilege using permissions block in YAML\n- Pin third-party Actions to specific git commit SHAs for supply chain security\n- Enable Step Debug logging on GitHub runners\n- Generate custom Job Summaries in markdown format to report test results
