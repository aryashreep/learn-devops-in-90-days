⚙️ Main Content

1. Job Dependencies (`needs`)

By default, all jobs in a workflow execute in parallel. To run them sequentially, use the needs keyword:

jobs:
  test:
    runs-on: ubuntu-latest
  deploy:
    needs: test # Runs only after 'test' passes
    runs-on: ubuntu-latest

2. Scoping Environment Variables

Variables set at the top-level env: are available to all jobs. Variables defined inside a job are restricted to that job. Variables defined in a step are restricted to that step.

3. If Conditionals

Control step or job execution dynamically: if: github.ref == 'refs/heads/main'.

⌨️ Try It Yourself
# Write this configuration in your test pipeline:
name: Scopes and Conditionals
on: push
env:
  GLOBAL_VAR: "I am global"
jobs:
  check:
    runs-on: ubuntu-latest
    steps:
      - name: Print Env
        run: echo "Global is $GLOBAL_VAR"
      - name: Staging Deploy Check
        if: github.ref == 'refs/heads/main'
        run: echo "Deploying to main only!"
