# 🗓️ Day 45 — Jobs, Steps, Env Vars and Conditionals

Welcome to **Day 45** of the **#LearnDevOpsIn90Days** challenge 🚀

## 🎯 Today's Goal
Construct multi-job pipelines, configure scopes of environment variables, and use if conditionals.

## 🧠 Key Learnings
- Map workflow components hierarchically (Workflow, Jobs, Steps)\n- Set environment variables at workflow, job, and step scopes\n- Establish job dependencies using the 'needs' keyword\n- Apply 'if' conditionals to control job/step execution based on contexts
