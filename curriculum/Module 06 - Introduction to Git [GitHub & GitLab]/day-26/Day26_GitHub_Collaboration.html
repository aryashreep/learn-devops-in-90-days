What will we learn today?

Today we will understand the basic meaning of **Clone vs Fork**. How to manage remote repositories, **SSH vs HTTPS** authentication, and the favorite of pro DevOps engineers: **GitHub CLI (gh)**.

🎯 LEARNING OBJECTIVES
  • Distinguish: Master the difference between Clone and Fork.
  • Authenticate: Set up SSH keys for secure cloud communication.
  • Synchronize: Learn `push`, `pull`, and tracking branches (`-u`).
  • Efficiency: Get started with GitHub CLI (`gh`).

💡 Kyu Seekhein? Kyunki real projects mein manual uploads nahi, automated push-pull workflow chalta hai!

💡 ANALOGY: The Shared Notebook

1. Clone: Photocopy karwa li (Your local copy).
2. Fork: Notebook ki copy apne naam pe register karli (Your own repo).
3. Push: Apne updates shared notebook mein likh diye.
4. Pull: Dusron ke updates apni photocopy mein update kar liye.

📌 Key Concepts: Clone vs Fork

Clone

"Seedha download local machine pe."

  • Copy from Repo ➔ Local
  • Connected to the original.
VS

Fork

"GitHub pe apni khud ki copy banana."

  • Copy from Repo ➔ Your GitHub
  • Open source collab ke liye best!
