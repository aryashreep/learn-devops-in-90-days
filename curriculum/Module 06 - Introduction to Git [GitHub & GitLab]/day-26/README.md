## 🎯 Today's Goal
Learn how to collaborate with others using GitHub, manage remote repositories, and use the GitHub CLI.

## 🧪 Hands-on Lab
1. Create a new repository on GitHub.
2. Link your local repo: `git remote add origin [URL]`.
3. Push your first commit: `git push -u origin main`.
4. Install GitHub CLI (`gh`) and create a repo from terminal.
