🎯 LEARNING OBJECTIVES
  • Isolate: Create and switch branches for safe development.
  • Synchronize: Connect your local repo to GitHub via `git remote`.
  • Publish: Push your code to the cloud for collaboration.
  • Strategy: Understand the `main` vs `dev` branch workflow.

🏷️ Branch Naming & Management

1. Naming Conventions — Professional bano!

Random naam mat rakho! Professional teams ye prefixes use karti hain:

  • feature/add-login: Naya feature banane ke liye.
  • bugfix/fix-header: Chota bug fix karne ke liye.
  • hotfix/server-crash: Urgent production issues ke liye.

2. Cleanup — Kuch bhi kachra mat chhodo!

  • git branch -m old-name new-name: Branch rename karne ke liye.
  • git branch -d branch-name: Kaam hone ke baad branch delete karne ke liye. (Safai zaruri hai!)
