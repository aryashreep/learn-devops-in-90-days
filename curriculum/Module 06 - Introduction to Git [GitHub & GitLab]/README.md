# 🐙 Module 05: Introduction to Git [GitHub & GitLab]

Welcome to **Module 05**! In this module, we transition from being simple file editors to master "Time Travelers" of code. Git is the foundation of modern DevOps.

## 🎯 Module Overview
This 7-day deep-dive takes you from your first `git init` to professional team collaboration and advanced surgical recovery tools.

| Day | Topic | Key Focus |
|---|---|---|
| **Day 22** | Git Foundations | Setup, Stages (Working, Staging, Repo), Basic Commands. |
| **Day 23** | Branching & Workflows | Parallel development, feature branches, switching. |
| **Day 24** | GitHub Collaboration | Clone vs Fork, SSH Auth, GH CLI, Remote sync. |
| **Day 25** | Integrating Work | Merge vs Rebase, Squash commits, Pull Rebase. |
| **Day 26** | Undoing & Recovery | Reset, Revert, Reflog (The Savior), Stashing. |
| **Day 27** | Team Collaboration | Pull Requests (PRs), Conflict Resolution, Branching Strategies. |
| **Day 28** | Git Mastery | Advanced Tools: Bisect, Tags, Hooks, Worktree. |
