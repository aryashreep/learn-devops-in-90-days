# 🗓️ Day 28 — Undoing & Surgical Edits

Welcome to **Day 28**! Today we learn how to fix mistakes and recover lost work.

## 🧠 Pro Module
[🎓 Day 28 Pro Module](./Day26_Git_Recovery.html)

## 🎯 Today's Goal
Master the art of Git "Surgery"—undoing changes safely and using the reflog to rescue deleted commits.

## 🧪 Hands-on Lab
1. Use `git reset --soft` to undo a commit but keep changes.
2. Use `git revert` to fix a mistake on a shared branch.
3. Accidentally delete a branch and find its SHA using `git reflog`.
4. Cherry-pick a specific commit from `dev` to `main`.
