# 🏆 Module 05 Mastery Exam: Git & GitHub

Welcome to the **Git Mastery Exam**! This assessment tests your knowledge of version control, collaboration workflows, and advanced surgical operations.

---

## 📝 Part 1: Git Foundations & Branching

**1. What is the main difference between Git and a Centralized VCS (like SVN)?**
- A) Git is faster because it uses cloud storage
- B) Git stores every version as a full file copy
- C) In Git, every user has a full copy of the entire project history locally
- D) Git only works on Linux
- **Ans: C**

**2. Which command is used to set your identity in Git globally?**
- A) `git identity set`
- B) `git config --global user.name "Name"`
- C) `git user set --name "Name"`
- D) `git init --user "Name"`
- **Ans: B**

**3. If you have modified a file, what is the next step to include it in a commit?**
- A) `git push`
- B) `git save`
- C) `git add`
- D) `git lock`
- **Ans: C**

**4. What does the command `git checkout -b feature-alpha` do?**
- A) Deletes the branch feature-alpha
- B) Merges feature-alpha into main
- C) Creates a new branch named feature-alpha and switches to it
- D) Checks if feature-alpha has any bugs
- **Ans: C**

**5. How do you permanently remove a file from both your disk and Git tracking?**
- A) `git rm <file>`
- B) `git rm --cached <file>`
- C) `rm <file>`
- D) `git hide <file>`
- **Ans: A**

---

## 🚀 Part 2: Collaboration & Integration

**6. What is a 'Fork' in GitHub?**
- A) A command to delete a repository
- B) A personal copy of someone else's repository on your GitHub account
- C) A way to merge code without review
- D) A physical device to store Git data
- **Ans: B**

**7. Which command connects your local repository to a remote server on GitHub?**
- A) `git connect [URL]`
- B) `git remote add origin [URL]`
- C) `git push --init [URL]`
- D) `git sync [URL]`
- **Ans: B**

**8. What is the main difference between `git merge` and `git rebase`?**
- A) Merge is faster than Rebase
- B) Rebase creates a merge commit, Merge does not
- C) Merge preserves history as it happened; Rebase rewrites history to be linear
- D) Rebase is for local files only
- **Ans: C**

**9. What does the `--force-with-lease` flag do during a push?**
- A) Overwrites remote changes without checking
- B) Only pushes if no one else has updated the remote branch since your last fetch
- C) Merges the code automatically
- D) Deletes the remote branch
- **Ans: B**

**10. How do you resolve a Merge Conflict?**
- A) Delete the repository and clone again
- B) Run `git solve --conflict`
- C) Manually edit the file to remove markers (`<<< === >>>`) and commit the result
- D) Ask GitHub to fix it automatically
- **Ans: C**

## 🥷 Part 3: Advanced Operations

**11. You accidentally did a `git reset --hard` and lost commits. Which command can help find them?**
- A) `git history --all`
- B) `git reflog`
- C) `git find-lost`
- D) `git undo`
- **Ans: B**

**12. What is the purpose of `git stash`?**
- A) To delete temporary files
- B) To permanently archive the project
- C) To temporarily "hide" uncommitted changes to work on a clean branch
- D) To speed up the internet connection
- **Ans: C**

**13. Which command allows you to apply a single specific commit from another branch?**
- A) `git merge --single`
- B) `git cherry-pick [SHA]`
- C) `git copy-commit`
- D) `git rebase --pick`
- **Ans: B**

**14. What is `git bisect` used for?**
- A) Slicing a large file into two
- B) Finding the specific commit that introduced a bug using binary search
- C) Creating two branches at once
- D) Merging two repositories
- **Ans: B**

**15. What are Git Hooks?**
- A) Physical brackets to hold servers
- B) Scripts that Git executes before or after events like commit or push
- C) Plugins for the browser
- D) Short names for long commands
- **Ans: B**
