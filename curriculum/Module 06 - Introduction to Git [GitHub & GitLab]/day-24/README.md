# 🗓️ Day 24 — Introduction to Git: Your First Repository

Welcome to **Day 24**! Today we begin our journey into **The Time Machine**. No more worrying about "What if I delete this?" or "How do I undo that?" — Git is your safety net.

## 🎯 Today's Goal
Understand what Version Control is and set up your very first Git repository to track your project history.

## 🧠 Key Learnings
- **The Concept:** Why DevOps engineers can't survive without Version Control.
- **Git Config:** Setting your identity (Name & Email).
- **The 3 Stages:** Working Directory ➔ Staging Area ➔ Local Repository.
- **Commands:** `git init`, `git status`, `git add`, `git commit`.
