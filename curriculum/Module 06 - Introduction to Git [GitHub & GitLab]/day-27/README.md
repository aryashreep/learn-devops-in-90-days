# 🗓️ Day 27 — Integrating Work (Merge vs Rebase)

Welcome to **Day 27**! Today we learn how to bring parallel branches together.

## 🧠 Pro Module
[🎓 Day 27 Pro Module](./Day27_Integrating_Work.html)

## 🎯 Today's Goal
Master the two main ways of integrating code changes and understand when to use each.

## 🧪 Hands-on Lab
1. Create a feature branch and make commits.
2. Update `main` with a new commit.
3. Switch to feature and `rebase main`.
4. Create another branch and `merge` it into `main` to see the difference.
