What will we learn today?

Today we will discuss the methods of Git integration: **Merge** (History preserving) and **Rebase** (History rewriting). What is fast-forward merge, when to use squash commit, and why `pull --rebase` is a favorite of DevOps engineers.

🎯 LEARNING OBJECTIVES
  • Understand: The philosophy of Fast-Forward vs Merge Commits.
  • Execute: Perform a clean Rebase to keep a linear history.
  • Optimize: Use Squash commits to clean up "messy" commit logs.
  • Coordinate: Master `fetch` vs `pull` and the rebase workflow.

💡 Kyu Seekhein? Kyunki gandi Git history troubleshoot karna nightmare hota hai. Pro teams clean logs chahti hain!

💡 ANALOGY: The Train Tracks

1. Merge: Do patriyan (tracks) aakar ek ho gayi (Side-by-side history).
2. Rebase: Apni train ke dibbe (commits) utha kar doosri patri ke aage laga diye (Linear history).

📌 Key Concepts: Merge vs Rebase

Merge

"History will remain as it was. Record of every event."

  • Creates a 'Merge Commit'.
  • Preserves the chronological order.
  • Good for: Public history.
VS

Rebase

"Commit history to rewrite it. Make it completely clean!"

  • Moves commits to a new base.
  • Linear, easy to read.
  • Good for: Feature branches.

⚠ GOLDEN RULE: Kabhi bhi 'main' branch pe Rebase mat karna agar wo shared hai!

📡 Fetch, Pull & The Pro Way
  • git fetch: Sirf jaankari lata hai cloud se. Local code change nahi hota. "Sirf dekho!"
  • git pull: Fetch + automatic Merge. History mein extra merge commits add kar sakta hai.
  • git pull --rebase: Fetch + Rebase. Aapke local commits ko cloud ke latest commits ke aage laga deta hai. (First choice of DevOps Engineers!)
📦 Squash: Cleaning the Mess

Squash Commit — "10 ka 1"

If you have committed 10 "wip", "fix typo" commits on your feature branch, then commit them on the `main` branch. Merge by doing one word Squash. This 'main' story looks very professional!

git merge --squash feature-branch
▶ TRY IT YOURSELF

1. git merge feature-branch (Mix it!)

2. git rebase main (Keep it linear!)

3. git pull --rebase (Professional way!)
