📇 Quick Reference Cards
🔤 Variables & Strings
  • name="Golu" — assign variable
  • echo $name — access value
  • read -p "Enter: " var — user input
  • ${name:-default} — default value
  • ${#name} — string length
🔄 Conditionals
  • if [ "$x" = "yes" ]; then
  • elif [ -f "$file" ]; then
  • else ... fi
  • [ -d "$dir" ] — check directory
  • [ $? -eq 0 ] — exit status check
🔁 Loops
  • for i in {1..5}; do
  • for f in *.log; do
  • while read line; do
  • until [ $x -ge 5 ]; do
  • break / continue
⚙️ Functions
  • my_func() { ... }
  • log() { echo "[LOG] $1"; }
  • local var=5 — local scope
  • return 1 — explicit exit code
  • my_func "arg1" "arg2" — call

📋 The Master Template

Ye template har naye script project ki foundation hai. Copy, paste, and build! 

#!/bin/bash
#=============================================
# Script:     template.sh
# Author:     Golu (Aryashree's Student)
# Date:       $(date +%F)
# Description: Master template for shell scripts
# Usage:      ./template.sh [options]
#=============================================

set -euo pipefail   # Safety: exit on error, undefined vars, pipe fails

# ---------- Constants ----------
SCRIPT_NAME=$(basename "$0")
LOG_FILE="/var/log/${SCRIPT_NAME%.sh}.log"

# ---------- Functions ----------
log() {
    local level="${2:-INFO}"
    echo "[$(date '+%Y-%m-%d %H:%M:%S')] [$level] $1" | tee -a "$LOG_FILE"
}

error_exit() {
    log "FATAL: $1" "ERROR"
    exit 1
}

usage() {
    echo "Usage: $SCRIPT_NAME [options]"
    echo "  -h    Show help"
    echo "  -v    Verbose mode"
    exit 0
}

# ---------- Main Logic ----------
main() {
    log "Starting script execution..."
    
    # Check arguments
    [[ $# -eq 0 ]] && usage
    
    # Your business logic here
    log "Processing complete!"
}

main "$@"

💡 set -euo pipefail — ye teen flags bash scripts ko production-ready banate hain

🔀 Redirection & Pipes Cheat Sheet
cmd > file — stdout to file
cmd 2> file — stderr to file
cmd &> file — both to file
cmd >> file — append
cmd1 | cmd2 — pipe output
cmd < file — input from file
2>&1 — stderr to stdout
2>/dev/null — silence errors
⚖️ Comparison Operators

🔢 Numbers

  • -eq — equal
  • -ne — not equal
  • -lt — less than
  • -le — less/equal
  • -gt — greater than
  • -ge — greater/equal

🔤 Strings

  • = — equal
  • != — not equal
  • -z — empty string
  • -n — non-empty
  • < — lexicographic less
  • > — lexicographic greater

📁 File Tests

  • -f — file exists
  • -d — directory exists
  • -x — executable
  • -r — readable
  • -w — writable
  • -s — size > 0

❓ Mini Quiz

1. Pichle command ka exit code check karne ke liye kaunsa variable use karte hain?

A) $1   B) $?   C) $!   D) $_

2. Script ko safe mode mein chalane ke liye kaunsa set flag sahi nahi hai?

A) set -e   B) set -u   C) set -x   D) set -o pipefail

3. Function ke andar variable ko sirf function tak limit karne ke liye kaunsa keyword?

A) local   B) global   C) static   D) readonly

✅ Answer Key

1-B ($? = last exit code)  |  2-C (-x is debug mode, not safety)  |  3-A (local = function scope)
