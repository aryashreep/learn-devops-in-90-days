🎯 Why a Log Analyzer?

Every server in production generates GBs of logs daily. DevOps Engineers Do not scroll manually - write scripts that identify errors, count warnings, And generate Formatted Reports for the stakeholders!

🎯 Learning Objectives
  • Parsing: Use grep -c to count error/warning lines inside a script.
  • Extraction: Use awk to identify the most frequent error message.
  • Reporting: Format output into a professional summary file with $(date +%F).
  • Automation Logic: Combine searching, counting, and file writing into one log_analyzer.sh.
🏗️ Script Architecture
#!/bin/bash
# log_analyzer.sh — Intelligence Agent v1.0

LOG_FILE=$1                    # Argument: input log file path
REPORT="log_report_$(date +%F).txt"  # Output: timestamped report

# Count occurrences
TOTAL_ERRORS=$(grep -c "ERROR" "$LOG_FILE")
TOTAL_WARNINGS=$(grep -c "WARNING" "$LOG_FILE")

# Find most frequent error (top 1)
TOP_ERROR=$(grep "ERROR" "$LOG_FILE" | awk -F'] ' '{print $2}' | sort | uniq -c | sort -rn | head -1)

# Find CRITICAL line numbers
CRITICAL_LINES=$(grep -n "CRITICAL" "$LOG_FILE" | awk -F: '{print $1}')

# Generate report
cat > "$REPORT" <<EOF
---------------------------------
Log Analysis Report - $(date +%F)
---------------------------------
Total Errors: $TOTAL_ERRORS
Total Warnings: $TOTAL_WARNINGS
Most Frequent Error: $TOP_ERROR
CRITICAL Events on lines: $CRITICAL_LINES
---------------------------------
EOF

echo "Report generated: $REPORT"

💡 Key Techniques: grep -c counts, awk -F splits fields, $(date +%F) timestamps, heredoc <<EOF writes formatted files

🔧 Tools in Action

🔍 grep -c

grep -c "ERROR" access.log → 45

Count matching lines. Fast, efficient, no loops needed.

📊 awk -F

awk -F'] ' '{print $2}'

Split each line by '] ' and extract the message part.

📅 date +%F

log_report_$(date +%F).txt

Auto-generates today's date (YYYY-MM-DD) in filename.

⚠️ CRITICAL Detection

grep -n "CRITICAL" log | awk -F: '{print $1}'

Line numbers of critical events for immediate action.

💡 Analogy: Airport Security Scanner

1. Log File: Airport CCTV footage (crore events).
2. grep "CRITICAL": "Suspicious bag" alarm sounds (Filter).
3. awk '{print $N}': Just extract the name of the owner of the bag.
4. Report: Give daily summary to the security chief (Output).

❓ Mini Quiz

1. How to capture argument (log file path) in script?

A) $LOG_FILE   B) $1   C) $@   D) $#

2. Which flag of grep tells only the count, not the lines?

A) -n   B) -v   C) -c   D) -i

3. Which limit string should be used to expand the variable in Heredoc (cat > file << EOF)?

A) 'EOF'   B) "EOF"   C) <<-EOF   D) None — default expand hota hai

✅ Answer Key

1-B ($1 captures first argument)  |  2-C (-c counts matches)  |  3-D (bare EOF expands variables)
