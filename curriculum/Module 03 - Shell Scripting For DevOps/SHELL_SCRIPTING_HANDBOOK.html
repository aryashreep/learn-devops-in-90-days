The Shell Scripting Handbook

Complete Master Guide: Zero to Production-Safe
"Think of the Shell as the steering wheel of your OS. Instead of clicking icons, you type commands. Bash is just the most popular brand of shell!"

1. What is Shell & Bash?

Bash is the "glue" of DevOps. It connects different tools together. You use it to navigate servers, install software, run tests, and manage cloud infrastructure.
  • Shell: A command-line interpreter that processes commands.
  • Bash: The default shell on most Linux distributions.
  • Terminal: The window where you type shell commands.
# Basic command echo "Hello, DevOps!" # Check which shell you are using echo $SHELL

2. How a Shell Script Works

A shell script is simply a text file containing a list of commands. Running the file runs all commands automatically. Manual mehnat khatam, automation shuru!
  • Interpreter: Bash reads the file top-to-bottom and executes lines sequentially.
  • Execution: Scripts are interpreted, not compiled.
# Run a script bash myscript.sh # Or if executable ./myscript.sh

3. Script Structure & Shebang

The "Shebang" (`#!`) is the first line. It tells the computer exactly which interpreter to use. Necessary for portability!
#!/bin/bash # This is a comment. The computer ignores this line. echo "The script is starting..."
To make it runnable: chmod +x myscript.sh

4. Variables & Dynamic Data

Variables are labeled boxes. Assignment: `VAR=value` (No spaces!). Access: `$VAR`.
APP_NAME="MyApp" PORT=8080 echo "Starting $APP_NAME on port $PORT" # Command Substitution CURRENT_DATE=$(date) echo "Server started at: $CURRENT_DATE"

5. Input & Arguments

Arguments allow you to pass information into a script right when you run it. It's like giving ingredients to a chef!
  • $1, $2: Positional Parameters.
  • $#: Total number of arguments.
  • read: Prompts the user for interactive input.
#!/bin/bash echo "Deploying file: $1" read -p "Are you sure? (y/n) " CONFIRM echo "User entered: $CONFIRM"

6. Conditionals (if, else)

Safety checks. "If the directory exists, clean it; otherwise, create it."
COUNT=10 # Numeric comparison if [[ $COUNT -gt 5 ]]; then echo "Count is greater than 5" else echo "Count is small" fi # String comparison if [[ "$STATUS" == "success" ]]; then echo "Great job!" fi

7. Loops (for, while)

Loops let you repeat a task. "For every file in this folder, upload it."
# FOR LOOP for NAME in ServerA ServerB ServerC; do echo "Pinging $NAME..." done # WHILE LOOP COUNT=1 while [[ $COUNT -le 3 ]]; do echo "Attempt $COUNT..." ((COUNT++)) done

8. Functions & Modularity

Functions are reusable mini-scripts. Write once, use again and again!
check_status() { local SERVICE=$1 echo "Checking status of $SERVICE..." } check_status "nginx" check_status "mysql"

9. File & Directory Checks

Before reading or entering, ask the computer: "Does this exist?"
  • -f: Is it a file?
  • -d: Is it a directory?
  • -x: Is it executable?
if [[ -d "/var/www/html" ]]; then echo "Folder exists!" else mkdir -p "/var/www/html" fi

10. Exit Codes ($?)

0 = Success. 1-255 = Error. Pipelines rely on these!
ls /folder STATUS=$? if [[ $STATUS -ne 0 ]]; then echo "Command failed!" exit 1 fi

11. Pipes & Redirects

  • |: Pipe output to another command.
  • >: Overwrite file.
  • >>: Append to file.
  • 2>&1: Redirect errors to the same place.
cat app.log | grep "error" | wc -l ls > file_list.txt echo "Update log" >> backup.log

12. Environment Variables

Global variables that affect how scripts run. Never hardcode secrets!
  • export: Makes variable global.
  • printenv: Lists all environment variables.
echo "User: $USER" export API_KEY="secret123"

13. Debugging Scripts

  • set -x: Debug mode (prints every command).
  • set -e: Exit immediately on error.
  • shellcheck: The ultimate linting tool.
set -x echo "Variable is $VAR" set +x

14. Cron Jobs & Scheduling

Time-based job scheduler. * * * * * = Minute, Hour, Day, Month, DayOfWeek.
# Run every day at 2:30 AM 30 2 * * * /path/to/backup.sh

15. Writing Production-Safe Scripts

"Reliability is everything. Production-safe scripts fail safely and predictably."
#!/bin/bash set -euo pipefail # The Safety Net # Defensive deletion rm -rf "${DIRECTORY:?}/tmp" echo "Script finished successfully"
