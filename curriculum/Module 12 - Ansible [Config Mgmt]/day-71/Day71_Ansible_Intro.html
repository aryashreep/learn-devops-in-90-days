🏗️ Ansible Architecture

Ansible follows a push-based, agentless architecture. Unlike Chef or Puppet which require agents on every node, Ansible connects via SSH and pushes instructions temporarily.

Control Node                    Managed Nodes
┌──────────────┐               ┌──────────────┐
│  Ansible     │  ─── SSH ──→  │  Node 1       │
│  Inventory   │               │  (Python)     │
│  Playbooks   │  ─── SSH ──→  ├──────────────┤
│  Modules     │               │  Node 2       │
│  ansible.cfg │  ─── SSH ──→  │  (Python)     │
└──────────────┘               └──────────────┘

Key Point: Managed nodes only need Python installed. No agent, no daemon, no extra configuration!

📋 Inventory Management

The inventory file defines which hosts Ansible manages. Two formats are supported:

INI Format (hosts.ini)

[webservers]
web1.example.com
web2.example.com ansible_user=ubuntu

[databases]
db1.example.com
db2.example.com

[all:vars]
ansible_user=admin
ansible_ssh_private_key_file=~/.ssh/id_rsa

YAML Format (hosts.yml)

all:
  children:
    webservers:
      hosts:
        web1.example.com:
          ansible_user: ubuntu
        web2.example.com:
    databases:
      hosts:
        db1.example.com:
        db2.example.com:
⚡ Ad-Hoc Commands

Ad-hoc commands let you execute quick tasks without writing playbooks:

# Ping all hosts (test connectivity)
ansible all -m ping

# Run command on webservers group
ansible webservers -m command -a "uptime"

# Install package on all Ubuntu hosts
ansible all -m apt -a "name=nginx state=present" --become

# Gather system facts (filtered)
ansible all -m setup -a "filter=ansible_distribution*"

# Copy a file to managed nodes
ansible all -m copy -a "src=/tmp/file.txt dest=/tmp/file.txt"
💿 Installing Ansible
# Ubuntu/Debian
sudo apt update && sudo apt install -y ansible

# Verify
ansible --version

# Check configuration
ansible-config list | grep CONFIG_FILE

# Ansible config file location: /etc/ansible/ansible.cfg

Jagu's Tip: Create a project-level ansible.cfg to keep configurations organized per project!
