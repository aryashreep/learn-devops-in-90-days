# ⚙️ Module 12: Ansible [Configuration Management]

Welcome to **Module 12**! In this module, we master **Ansible** — the industry-standard, agentless IT automation engine for configuration management, application deployment, and task orchestration. Created by Red Hat, Ansible uses a simple YAML-based language (playbooks) to automate repetitive tasks across thousands of servers.

---

## 🎯 Module Overview
This 5-day module will take you from Ansible basics to confident automation engineer, covering everything from inventory management to building reusable roles and a real-world deployment project.

| Day | Topic | Key Focus |
|---|---|---|
| **Day 71** | [Introduction to Ansible & Inventory Setup](./day-71/README.md) | Architecture, installation, inventory files, ad-hoc commands |
| **Day 72** | [Ansible Playbooks & Modules](./day-72/README.md) | YAML syntax, plays, tasks, file/pkg/service modules |
| **Day 73** | [Variables, Facts, Conditionals & Loops](./day-73/README.md) | Variable precedence, facts gathering, when, loop, handlers |
| **Day 74** | [Roles, Galaxy, Templates & Vault](./day-74/README.md) | Role structure, Ansible Galaxy, Jinja2 templates, secret encryption |
| **Day 75** | [Project: Automate Docker & Nginx Deployment](./day-75/README.md) | End-to-end automation of Docker + Nginx on target servers |
