## 🚀 Quick Start for Contributors

```bash
# 1️⃣  Fork this repository
#     Click the Fork button on the top-right of the GitHub page

# 2️⃣  Clone your fork
git clone https://github.com/<your-username>/learn-devops-in-90-days.git
cd learn-devops-in-90-days

# 3️⃣  Create a branch for your contribution
git checkout -b day-14-notes

# 4️⃣  Make your changes in the correct folder
#     All day content lives under content/day-XX/

# 5️⃣  Commit with a clear message
git commit -m "day-14: add python data structures notes and examples"

# 6️⃣  Push and open a Pull Request
git push origin day-14-notes
```

---

## 📁 Where to Put Your Work

All content lives inside the `content/` folder:

```
content/
├── day-01/
│   ├── README.md       ← task description + your notes
│   └── scripts/        ← any shell or python scripts (optional)
├── day-02/
│   └── README.md
...
```

> ⚠️ **Only edit the day folder(s) you worked on.**
> Do not modify other days' content in the same pull request.

---

## ✅ Pull Request Checklist

Before submitting your PR, confirm all of the following:

- [ ] 📂 Changes are inside the correct `content/day-XX/` folder
- [ ] 📝 Your `README.md` follows the day template (see below)
- [ ] 🔤 Filenames match the expected structure exactly
- [ ] 💬 Commit message is clear and follows the format: `day-XX: short description`
- [ ] 🚫 No emojis inside `README.md` content files
- [ ] ✂️ Content is concise and practical — no copy-paste from tutorials
- [ ] 🔗 Any external links are working and relevant

---

## 📝 Day README Template

Every `content/day-XX/README.md` should follow this structure:

```markdown
# Day XX — Topic Name

## Task
One clear sentence describing what today's task is.

## What I Did
Brief summary of the steps you took to complete the task.

## Key Learnings
- Learning point 1
- Learning point 2
- Learning point 3

## Commands / Code Used
\`\`\`bash
# Any commands or code from today's task
\`\`\`

## References
- [Resource name](URL)
- [Resource name](URL)
```

---

## 💬 Commit Message Format

| Type | Format | Example |
|---|---|---|
| Notes | `day-XX: topic — notes` | `day-08: git basics — notes` |
| Task complete | `day-XX: topic — task complete` | `day-16: docker intro — task complete` |
| Fix | `fix: day-XX short description` | `fix: day-22 broken link` |
| Typo | `typo: day-XX short description` | `typo: day-05 spelling correction` |

---

## 🚫 What Not to Do

- ❌ Do not modify another contributor's content without their consent
- ❌ Do not copy-paste content from blogs or tutorials without proper credit
- ❌ Do not raise a PR that edits multiple unrelated days at once
- ❌ Do not add promotional or affiliate links
- ❌ Do not use emojis inside the day `README.md` content files

---

## 🧭 Code of Conduct

This is an open, welcoming community. We expect all contributors to:

- 🤝 Be respectful and supportive to others
- 💬 Give constructive feedback — not criticism
- 🌍 Welcome learners of all backgrounds and experience levels
- 🙏 Credit others when building on their work

Disrespectful behaviour will result in removal from the project.
